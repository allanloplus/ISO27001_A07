# ISO 27001:2022 實體安全（Physical security）動畫教學簡報

以 ISO/IEC 27001:2022 附錄A 控制屬性「運作流程（Operational capabilities）＝實體安全」為範圍，
涵蓋 **區域安全 7.1～7.6** 與 **設備安全 5.37、6.7、7.7～7.14**，從三個面向講解：

1. **ISMS 作業重點**：區域安全、設備安全逐條重點＋兩個管理實務案例（裝修期間機房門被撐開、業務筆電車上失竊）
2. **稽核查核重點**：稽核員四個工具、逐條查核清單、私房查核技巧、「追一台硬碟的一生」
3. **常見的缺失**：TOP 10 常見缺失、不符合事項寫法範例（以 7.14 為例）、隨堂測驗與總結

由 Q 版講師 **Allan Lo**（台灣男聲）主講，助教 **阿拉蕾** 串場，全長約 13 分鐘。

## 修改講稿後重新產生

```bash
pip install edge-tts                      # 需要 ffmpeg、node 與 playwright
python3 tools/build_audio.py              # 重新產生旁白與 timing.js
python3 -m http.server 8765 &             # 本機提供檔案
node tools/render_video.cjs http://localhost:8765/index.html video/輸出.mp4 15
```

`scenes.js` 每句台詞的欄位：`s` 說話者（`A` Allan／`R` 阿拉蕾）、`t` 台詞、`r` 顯示到第幾個項目、`h` 強調第幾個項目、`e` 表情（Allan：smile laugh think confused wow point wink talk；阿拉蕾：wink laugh think wow confused talk cry excited）。

> 角色造型採用講師提供的角色設定圖（`assets/source/`）。更換角色圖後執行 `python3 tools/build_characters.py`，再重新輸出影片即可。

# 實體安全大冒險：互動闖關版（`zone-game/`）

製作：Allan Lo 顧問，2026/10/18

不是單向播放的影片，而是由使用者親自操控機房管理者「阿哲」走動。走到區域或情境點時，才觸發說明與互動：情境選擇、填寫表單、地圖找碴、配對分類，以及刷卡＋密碼。關卡內容與影片版相同（13 關，16 枚附錄A徽章）。選錯或填錯會記一筆不符合事項並扣合規分數，破關後產生可列印的「稽核報告」。

- **操作**：方向鍵或 WASD 移動，Shift 快跑；也可以直接點地圖，阿哲會自動尋路走過去。Enter／空白鍵繼續對話，M 切換全圖。
- **門禁**：牆壁、家具會擋路。紅區（R-01、R-02）從外面進入要輸入密碼（教學用密碼 2468）；Y-04 研發／財務區不是阿哲的權責區域，進不去。
- **互動**：
  - 表單：訪客登記簿、L4-30、L4-31、L4-33、L4-61、L4-62
  - 巡檢判讀：L4-63
  - 地圖找碴：玻璃隔間防窺、配線間佈纜、機房環境、下班淨空
  - 配對：區域分級、保養頻率、資料清除方式
  - 卡＋密碼門禁
- **計分**：每筆不符合事項 −5 分；欄位未填完就送出只會提醒，不扣分。稽核報告會列出每筆不符合事項的情境、你的作法、正確作法與依據條文。
- **進度**：存在瀏覽器（localStorage），下次打開可以繼續；任務板可以跳到任一關。

|---|---|
| `zone-game/index.html` | 互動闖關版（以瀏覽器開啟；GitHub Pages 網址為 `…/zone-game/`） |
| `zone-game/missions.js` | 13 關的情境、題目、正確答案、錯誤說明與依據條文（改題目就改這裡） |

# 實體安全大冒險：成果驗收學習測驗（`zone-exam/`）

製作：Allan Lo 顧問，2026/10/18

大冒險結束後的學習成果驗收：20 題單選題，每題 5 分，**90 分以上通過**（最多錯 2 題）。

流程：

1. **填寫受測人員資料**：公司名稱、單位、姓名、職稱，四欄都必填，會印在證書上。
   - 頁面上附有個資蒐集說明。
   - 資料只存在使用者自己的瀏覽器，不會上傳。
2. **作答**：
   - 題目與選項的順序每次隨機。
   - 交卷前可以回頭修改；有題目未作答時無法交卷，並會列出漏答的題號。
3. **通過**：產生「通過證書」（1754×1240，A4 橫式比例）。
   - 下載 PNG，或「列印／存成 PDF」。
   - 證書內容：姓名、公司、單位、職稱、成績、通過日期、證書編號、學習範圍（L2-09、L3-02、L4 表單；附錄A 16 項）、課程講師 Allan Lo 顧問。
   - 可在頁面上修改證書資料後重新產生。
   - 通過後才公布 20 題的正確答案與解析。
4. **未通過**：

# 嵌入 Google Sites 與手機觀看

四個頁面（影片版、闖關版、探索版、成果驗收）都是靜態網頁，可以直接用 GitHub Pages 網址嵌入 Google Sites：

1. 在 Google Sites 中選「插入 → 嵌入 → 依網址」。
2. 貼上網址，例如 `https://allanloplus.github.io/ISO27001_A07/zone-explore/`。
3. 選「整個網頁」，再把嵌入框拉大。建議寬度拉滿；電腦上高度約為寬度的 0.6 倍。

需要注意的地方：

- **版面自動調整**：闖關版與探索版會依嵌入框（或手機螢幕）的寬高自動切換版面。
  - 寬螢幕：電腦版，右側是任務卡。
  - 直向窄框：手機版，地圖在上、任務卡從下方展開。
  - 橫向矮框：精簡版，任務卡在右側。
- **另開新視窗**：在嵌入框中，右上角的按鈕會變成「⤢ 新視窗」，可以用完整畫面操作。手機上很建議使用。影片版的全螢幕按鈕若被網頁擋下，也會改為另開新視窗。
- **鍵盤操作**：嵌入時要先點一下畫面，方向鍵才有作用。手機直接點地圖或探索點即可。
- **語音**：瀏覽器規定要先點擊才能播放聲音，所以開始畫面需要先按一次按鈕。
- **進度保存**：進度存在瀏覽器（localStorage）。有些瀏覽器會限制嵌入框內的儲存，這時重新整理後進度可能不見，但不影響操作。

- `vis~eng`：跟隨陪同；`vis~`：取消跟隨
- `eng.item=物品`：手上拿的東西；`eng!符號`：頭上表情
- `$旗標=值`：改變場景狀態；`cam:鏡頭`：移動鏡頭

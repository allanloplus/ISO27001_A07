# ISO 27001:2022 實體安全（Physical security）動畫教學簡報

以 ISO/IEC 27001:2022 附錄A 控制屬性「運作流程（Operational capabilities）＝實體安全」為範圍，
涵蓋 **區域安全 7.1～7.6** 與 **設備安全 5.37、6.7、7.7～7.14**，從三個面向講解：

1. **ISMS 作業重點**：區域安全、設備安全逐條重點＋兩個管理實務案例（裝修期間機房門被撐開、業務筆電車上失竊）
2. **稽核查核重點**：稽核員四個工具、逐條查核清單、私房查核技巧、「追一台硬碟的一生」
3. **常見的缺失**：TOP 10 常見缺失、不符合事項寫法範例（以 7.14 為例）、隨堂測驗與總結

由 Q 版講師 **Allan Lo**（台灣男聲）主講，助教 **阿拉蕾** 串場，全長約 13 分鐘。

## 檔案

| 檔案 | 說明 |
|---|---|
| `video/ISO27001_實體安全_動畫簡報.mp4` | 完整教學影片（1280×720，含旁白） |

| `tools/render_video.cjs` | 用 Playwright 逐格渲染並以 ffmpeg 合成 MP4 |

| `assets/chars/` | 從設定圖裁出的表情圖層（Allan 8 種、阿拉蕾 8 種） |

## 修改講稿後重新產生

```bash
pip install edge-tts                      # 需要 ffmpeg、node 與 playwright
python3 tools/build_audio.py              # 重新產生旁白與 timing.js
python3 -m http.server 8765 &             # 本機提供檔案
node tools/render_video.cjs http://localhost:8765/index.html video/輸出.mp4 15
```

`scenes.js` 每句台詞的欄位：`s` 說話者（`A` Allan／`R` 阿拉蕾）、`t` 台詞、`r` 顯示到第幾個項目、`h` 強調第幾個項目、`e` 表情（Allan：smile laugh think confused wow point wink talk；阿拉蕾：wink laugh think wow confused talk cry excited）。

> 角色造型採用講師提供的角色設定圖（`assets/source/`）。更換角色圖後執行 `python3 tools/build_characters.py`，再重新輸出影片即可。

# 實體安全大冒險：安全區域巡檢動畫（`zone-quest/`）

製作：Allan Lo 顧問，2026/10/18

遊戲式俯視平面圖動畫：機房管理者「阿哲」在公司樓層中走動，依 `doc/` 目錄中的 ISMS 四階文件，完成 13 個任務。
Allan 老師當關主講解，阿拉蕾當玩家提問。每完成一個任務，就取得對應的 ISO/IEC 27001:2022 附錄A 控制徽章，16 枚集滿即破關。全長約 14 分鐘。

- **依據文件**：`ISMS-L2-09 實體與環境安全管理程序書`、`ISMS-L3-02 機房與設備保護作業說明書`、`ISMS-L4-29～L4-63` 表單
- **ISO/IEC 27001:2022 運作流程**：A07 實體安全（Physical security）；部分作業同時屬 A04 資產管理、A13 持續性（編號依本公司程序書表頭）
- **附錄A 控制項**：7.1～7.14，以及屬性含實體安全的 5.37、6.7，共 16 項
- **安全區域**：依 L2-09 §5.2.1 與 L4-29 安全區域佈置圖，分為白區（公共區）、綠區（一般管制區）、黃區（限制區）、紅區（高風險區）。平面圖以 L4-29 圖例標示：▲出入口、◆門禁、●監視器、■消防、◎環控

| 檔案 | 說明 |
|---|---|
| `video/ISO27001_實體安全區域_巡檢大冒險.mp4` | 完整動畫影片（1280×720，含旁白） |
| `zone-quest/index.html` | 互動播放版：可暫停、拖曳進度、依關卡跳轉（以瀏覽器開啟，需與同資料夾檔案及 `assets/chars/` 一起） |

## 修改後重新產生

```bash
python3 tools/build_audio.py zone-quest   # 重新產生 zone-quest/narration.mp3、timing.js 與 build/zone-quest_narration.wav
npx http-server -p 8766 &                 # 本機提供檔案（需支援 Range，互動版才能拖曳進度）
node tools/render_video.cjs http://localhost:8766/zone-quest/index.html video/輸出.mp4 15 build/zone-quest_narration.wav
```

`zone-quest/scenes.js` 每句台詞除了 `s`、`t`、`e` 之外，還有：`k`（任務步驟打勾到第幾項）、`form`（展開哪一張表單卡）、`clear`（任務完成並取得徽章）、`do`（走位與場景動作）。`do` 的寫法如下：

- `eng>節點`：走過去；`eng>>節點`：跑過去；`eng=節點`：傳送
- `vis~eng`：跟隨陪同；`vis~`：取消跟隨
- `eng.item=物品`：手上拿的東西；`eng!符號`：頭上表情
- `$旗標=值`：改變場景狀態；`cam:鏡頭`：移動鏡頭
- 可加 `@秒數`、`@角色`、`@角色+秒數`，延後到指定時間或某角色走完後才執行
